# 🚀 Taiger7 - Telegram Content Automation Assistant

## 🎉 Welcome to Taiger7!

**Taiger7** - это мощный инструмент автоматизации обработки контента в Telegram-каналах с использованием искусственного интеллекта. Сервис позволяет автоматически забирать посты из одних каналов, обрабатывать их с помощью ИИ и публиковать в другие каналы с заданными интервалами.

### 💰 Ваш баланс: `<code>{BALANCE}</code>`🔋

### 🤖 Возможности сервиса:

• **Автоматическая обработка постов** - Извлечение, редактирование и переформулировка контента с помощью ИИ
• **Поддержка нескольких моделей** - Использование различных ИИ-моделей (OpenRouter, Hyperbolic)
• **Расписание публикаций** - Настройка задержек и интервалов между публикациями
• **Работа с медиа** - Поддержка текстов, изображений, видео и альбомов
• **Управление каналами** - Настройка "источник" и "приемник" каналов
• **Многопользовательская система** - Каждый пользователь имеет изолированный воркер

### 📊 Статус воркера: `<code>{WORKER_STATUS}</code>`

### 🎛️ Быстрые команды:
• `/start` - Главная панель управления и баланс
• `/balance` - Проверка текущего баланса
• `/worker` - Панель управления воркером
• `/logs` - Просмотр недавней активности
• `/help` - Справочная информация

### 📱 Открыть приложение:
Для полного функционала используйте Telegram Mini App с помощью кнопки "📱 Open Mini App" или через главное меню.

### 💡 Совет:
Используйте `/worker` для управления вашим агентом автоматизации. Агент может работать с вашими каналами даже когда вы не в сети!
