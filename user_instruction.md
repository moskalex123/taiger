# 🐯 Taiger.pro — инструкция пользователя

## 🎯 Для кого предназначен сервис
Taiger.pro помогает авторам Telegram‑каналов автоматизировать превращение черновиков в готовые публикации. Интерфейс разработан для новичков и продвинутых пользователей: первый может получить результат за пару минут, второй — гибко настроить постоянную обработку.

## ✅ Что нужно перед стартом
- 💼 Аккаунт Telegram с правами администратора в каналах, где будет работать помощник.
- 📱 Два канала: один для черновиков (источник), второй для публикаций (чистовик). Их можно создать заранее или через мастер правил.
- 🔐 Готовность пройти авторизацию: через Telegram Mini App (TMA) либо подтверждение по телефону и SMS/2FA.

## 🚪 Вход в систему
1. **Откройте приложение** — загрузится экран выбора языка (🇺🇸/🇷🇺). Предпочтение сохраняется в браузере.
2. **Попытка TMA-авторизации** 🤖 (если вход происходит из Telegram Mini App): сервис автоматически запросит токен и войдёт при успешном ответе.
3. **Классический вход** 📞 (если TMA недоступна):
   - введите номер телефона, дождитесь SMS-кода;
   - введите код, при необходимости укажите пароль 2FA;
   - новая учётка получит модальное приветствие с пояснением работы помощника.
4. При ошибке сети появится уведомление с подсказкой «Попробовать снова» — нажмите кнопку для повторной попытки.

## 🧭 Обзор интерфейса
После входа вас встретит один из режимов UI:
- **Лендинг** 🪄 — краткое описание сервиса и кнопка старта, если пользователь ещё не авторизован.
- **Оригинальный интерфейс** 🖥️ — классический дашборд с блоками баланса, воркера, логов и правил.
- **Редизайн** 🎨 — вкладочный интерфейс (Home, Activity, Channels, Settings). Переключиться можно через настройки → «Включить новый интерфейс».

### Главные элементы редизайна
- **Home** 🏠 — профиль, баланс, статус помощника и кнопка запуска/остановки.
- **Activity** 📈 — единый поток логов: реальное время, отложенные публикации, ошибки.
- **Channels** 🔁 — управление правилами через компонент ChannelPairs и плавающую кнопку «➕» для запуска мастера.
- **Settings** ⚙️ — выход, переключение дизайна, обновление данных TMA, ссылка на справку.
- **Уведомления** 🔔 — появляются правым верхним углом, автоматически скрываются, дублируют успехи/ошибки.

## 🚀 Быстрый старт (новичкам)
1. **Проверка каналов** — убедитесь, что помощник имеет права администратора в черновике и чистовике.
2. **Откройте Channels → ➕** — запустится мастер создания правила.
3. **Пройдите 4 шага мастера**:
   1. Выберите канал-источник (черновики).
   2. Настройте стиль обработки (AI инструкция, шаблон).
   3. Укажите расписание (интервал публикаций, время).
   4. Назначьте канал-получатель (чистовик).
4. **Наблюдайте прогресс** 🕘 — появится индикатор: остановка воркера → сохранение → запуск.
5. **Получите подтверждение** 💬 — уведомление «Правило создано и помощник запущен!» и активный статус «running».

## 🤖 Управление помощником
- Кнопка запуска доступна в блоке «Статус помощника» (Dashbord/Home).
- Состояния: `running` (🟢 работает), `stopped` (🔴 остановлен), `starting/stopping` (🟡 переключается), `auth_required` (🔒 требуется переавторизация), `error` (⚠️ возникла ошибка).
- Кнопка заблокирована, если нет активных правил или баланс < 0.
- Для смены аккаунта в TMA используйте Settings → «Refresh Account».

## 📊 Мониторинг и логи
- **Activity** или блок «Логи» показывает события в хронологическом порядке.
- Цветовые индикаторы: зелёный — успех, красный — ошибка, жёлтый — предупреждение, голубой — информация.
- Для подробностей наведите курсор или откройте уведомление.
- Отложенные посты и ошибки воркера (например, недостаточно средств) выводятся в отдельных секциях списка.

## ✏️ Работа с правилами
- **ChannelPairs** отображает все текущие связки каналов.
- Для правок воспользуйтесь контекстными кнопками внутри карточек (редактировать, удалить, клонировать).
- Валидация выполняется в реальном времени: сервис предупредит, если канал недоступен или нет прав.
- При создании/редактировании правила прогресс-индикатор и уведомления сообщат о каждом этапе.

## 🔄 Смена режима интерфейса
- В Settings включите или отключите «Redesigned UI». Переключение происходит сразу без перезагрузки.
- Настройки сохраняются в `localStorage`, поэтому при следующем входе выберется последний режим.

## 🛠️ Типичные проблемы и решения
- **Нет SMS-кода**: убедитесь, что номер указан с кодом страны и повторите запрос через 60 секунд.
- **Сообщение “auth_required”**: выйдите через Settings → Logout и войдите заново.
- **Статус “insufficient_funds” в логах**: пополните баланс в профиле Telegram и снова запустите помощника.
- **Нет обновления логов**: проверьте подключение WebSocket; при недоступности активируется резерв с периодическим опросом.
- **Поменяли аккаунт в Telegram Mini App**: нажмите «Refresh Account», приложение заново запросит токен.

## 📱 Мобильный доступ
- Все основные элементы адаптируются под экран смартфона.
- Уведомления растягиваются на ширину экрана, плавающая кнопка «➕» фиксируется внизу справа.
- Логин и мастер правил поддерживают touch‑жесты и виртуальную клавиатуру.

## 💡 Советы для продуктивности
- Используйте **Simple Mode** (простой сценарий) для пакетной обработки: заранее соберите посты в черновиках и запускайте обработку тогда, когда вам удобно.
- В **Advanced Mode** настройте детальные расписания и несколько каналов для регулярной автоматизации.
- Регулярно проверяйте вкладку Activity, чтобы отслеживать, как AI улучшает контент, и оперативно реагируйте на ошибки.

Успехов в автоматизации ваших Telegram‑каналов! 🚀
