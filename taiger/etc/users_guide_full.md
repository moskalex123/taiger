## Введение

**tAIger** — это сервис автоматизации Telegram с двумя режимами работы:
- **Режим Бота**: Интерактивный чат-бот для обработки текста и медиа с помощью ИИ
- **Режим Агента**: Автоматическая пересылка и обработка сообщений между каналами

Сервис поддерживает:
- 🌍 Двуязычный интерфейс (русский/английский)
- 🔋 Систему баланса (батареи)
- 💳 Оплату через Telegram Stars
- 📱 Telegram Mini App (TMA)
- ⚡ Гибридную обработку сообщений
- 🎯 Приоритетную систему на основе VIP-уровней

## Обзор системы

### Архитектура

Система состоит из следующих компонентов:

1. **FastAPI Backend**: RESTful API с WebSocket поддержкой
2. **Telegram Bot**: Интерактивный бот для обработки сообщений
3. **Worker Process**: Автономный агент для обработки каналов
4. **Vue.js Frontend**: Веб-интерфейс с двумя вариантами дизайна
5. **S3 Storage**: Хранение сессий и аватарок
6. **Redis**: Кеширование и управление очередью

### Режимы работы

| Режим | Описание | Основное назначение |
|-------|----------|-------------------|
| **Бот** | Интерактивный чат с ИИ-обработкой | Обработка отдельных сообщений, улучшение текста |
| **Агент** | Автоматическая пересылка между каналами | Автоматизация каналов, пересылка контента |

## Режим Бота

### Команды бота

#### `/start` — Главная панель управления

Показывает основную информацию о состоянии:
- Текущий баланс (батареи 🔋)
- Статус агента
- Кнопки для управления

**Пример вывода:**
```
🔋 Баланс: 100
🤖 Агент: Остановлен
```

#### `/balance` — Проверка баланса

Показывает текущее количество доступных батарей.

**Пример:**
```
🔋 Ваш баланс: 150 батарей
```

#### `/worker` — Управление агентом

Панель управления агентом с кнопками:
- **▶️ Запустить**: Запуск агента (если есть правила каналов)
- **⏹️ Остановить**: Остановка агента
- **🔄 Перезапустить**: Перезапуск агента

**Ограничения:**
- Агент можно запустить только если созданы правила каналов
- Баланс должен быть неотрицательным
- Агент может быть в очереди (система приоритетов)

#### `/logs` — Просмотр логов

Показывает последние 10 записей активности:
- Сообщения об ошибках
- Информация о запуске/остановке
- Состояние обработки

#### `/help` — Справка

Показывает список доступных команд и краткое описание.

### Обработка сообщений в боте

#### Текстовые сообщения

При отправке текстового сообщения в бот:

1. **Выбор модели**: Бот использует модель, настроенную в настройках (по умолчанию `bot_model_1`)
2. **Обработка через ИИ**: Текст отправляется в OpenRouter API для улучшения
3. **Возврат результата**: Обработанный текст возвращается пользователю

**Пример использования:**
```
Пользователь: Напиши более профессионально: "Привет всем, как дела?"
Бот: Добрый день, коллеги. Надеюсь, у вас всё хорошо.
```

**Ограничения:**
- Минимальный интервал между запросами к OpenRouter: **5 секунд**
- Стоимость зависит от используемой модели
- Баланс списывается за каждый запрос

#### Медиа-группы (альбомы)

При отправке группы фото/видео:

1. **Обнаружение группы**: Бот распознает медиа-группу (до 10 элементов)
2. **Обработка подписи**: Если есть подпись к группе, она обрабатывается через ИИ
3. **Возврат результата**: Обработанная подпись возвращается с медиа

**Пример:**
```
Пользователь: [Отправляет 3 фото с подписью "Мое путешествие"]
Бот: [Возвращает те же фото с улучшенной подписью]
```

**Ограничения:**
- Максимальный размер медиа-группы: **10 элементов**
- Обрабатывается только подпись к группе, не отдельные подписи к каждому фото

#### Отдельные медиа-файлы

При отправке отдельного фото/видео:

1. **Проверка подписи**: Если есть подпись, она обрабатывается через ИИ
2. **Возврат результата**: Обработанная подпись возвращается с медиа

**Ограничения:**
- Обрабатывается только текст подписи
- Сам медиа-файл не изменяется

### Система баланса бота

#### Получение батарей

Батареи (🔋) — это валюта сервиса для ИИ-обработки.

**Способы получения:**

1. **Покупка через Telegram Stars**:
   - Откройте меню бота
   - Выберите "Купить батареи"
   - Выберите пакет и оплатите через Telegram Stars

2. **Бесплатные батареи**:
   - Каждые **8 часов** можно получить бесплатные батареи
   - Кнопка "Получить бесплатные 🔋" появляется каждые 8 часов
   - Количество бесплатных батарей: **10 штук**

**Ограничения:**
- Бесплатные батареи можно получить только 1 раз за 8 часов
- Таймер отсчитывается с момента последнего получения

#### Списание батарей

Батареи списываются за:
- Обработку текстовых сообщений
- Обработку подписей к медиа
- Обработку подписей к медиа-группам

**Стоимость зависит от:**
- Используемой ИИ-модели
- Длины текста
- Типа операции

## Режим Агента (Worker)

### Основные понятия

#### Правило канала (Channel Pair)

Правило канала определяет автоматическую пересылку сообщений из **источника** в **цель**.

**Структура правила:**
- **Source Channel**: Канал-источник (откуда брать сообщения)
- **Target Channel**: Канал-назначение (куда отправлять)
- **Model**: ИИ-модель для обработки текста (опционально)
- **System Prompt**: Кастомный промпт для обработки (опционально)
- **Signature**: Подпись к пересылаемым сообщениям (опционально)
- **Active**: Статус правила (активно/неактивно)

**Пример правила:**
```
Источник: @news_channel
Цель: @my_channel
Модель: bot_model_1
Системный промпт: "Сократи текст"
Подпись: "Источник: @news_channel"
```

#### Состояния агента

| Состояние | Описание |
|-----------|----------|
| `stopped` | Агент остановлен |
| `starting` | Агент запускается |
| `running` | Агент работает и обрабатывает сообщения |
| `active` | Агент активен (синоним running) |
| `pending` | Агент в очереди на запуск |
| `processing` | Агент обрабатывает сообщения |
| `error` | Произошла ошибка |
| `auth_required` | Требуется авторизация |
| `maintenance` | Агент на обслуживании |
| `offline` | Агент оффлайн |

---

### Создание правил каналов

#### Через веб-интерфейс

1. Откройте веб-приложение
2. Перейдите на вкладку "Каналы"
3. Нажмите "Создать правило"
4. Заполните форму:
   - **Выберите канал-источник** (из списка подписанных каналов)
   - **Выберите канал-цель** (из списка каналов, где вы админ)
   - **Выберите модель** (опционально)
   - **Введите системный промпт** (опционально)
   - **Введите подпись** (опционально)
5. Нажмите "Сохранить"

#### Типы правил

**1. Простое правило (Simple Model)**
- Выбираете модель из списка
- Используете стандартный или кастомный промпт
- Подходит для базовой обработки текста

**2. Продвинутое правило (Advanced)**
- Полный контроль над параметрами
- Настройка температуры, max_tokens и других параметров
- Подходит для опытных пользователей

**3. Правило без ИИ (No AI)**
- Простая пересылка без обработки
- Не тратит баланс
- Подходит для прямой пересылки

#### Ограничения на правила

- **Минимум 1 правило** для запуска агента
- **Максимум 50 правил** на пользователя
- Канал-источник должен быть в списке подписанных каналов
- Канал-цель должен быть в списке каналов, где вы админ
- Нельзя создать дублирующее правило (одинаковые источник и цель)

### Управление агентом

#### Запуск агента

**Требования для запуска:**
1. ✅ Создано хотя бы одно правило канала
2. ✅ Баланс ≥ 0 (неотрицательный)
3. ✅ Сессия Telegram существует (файл сессии загружен)
4. ✅ Нет активного запущенного агента

**Как запустить:**
1. Через бота: `/worker` → "▶️ Запустить"
2. Через веб: Вкладка "Главная" → кнопка "Запустить"

**Процесс запуска:**
1. Агент добавляется в очередь
2. Система приоритетов определяет позицию в очереди
3. Когда наступает очередь, агент запускается
4. Агент подключается к Telegram
5. Агент начинает обрабатывать сообщения

**Время ожидания в очереди:**
- Зависит от VIP-уровня и текущей нагрузки
- VIP3: практически мгновенно
- VIP2: до 1 минуты
- VIP1: до 5 минут
- Обычный: до 10 минут
- Новичок: до 2 минут (первые 24 часа)

#### Остановка агента

**Как остановить:**
1. Через бота: `/worker` → "⏹️ Остановить"
2. Через веб: Вкладка "Главная" → кнопка "Остановить"

**Процесс остановки:**
1. Агент получает команду на остановку
2. Агент завершает текущую обработку
3. Агент отключается от Telegram
4. Агент удаляется из очереди

**Ограничения:**
- Агент остановится после завершения текущего сообщения
- Принудительная остановка может занять до 30 секунд

#### Перезапуск агента

**Как перезапустить:**
1. Через бота: `/worker` → "🔄 Перезапустить"
2. Через веб: Вкладка "Главная" → кнопка "Перезапустить"

**Процесс перезапуска:**
1. Агент останавливается
2. Агент запускается заново
3. Все настройки сохраняются

**Когда использовать:**
- Агент завис
- Произошла ошибка
- Нужно обновить правила

### Гибридная обработка

#### Что такое гибридная обработка?

Гибридная обработка объединяет два режима:
1. **Пакетная обработка**: Обработка накопленных сообщений за период отсутствия
2. **Реальное время**: Прослушивание новых сообщений в реальном времени

#### Пакетная обработка

**Когда происходит:**
- При первом запуске агента
- Если агент был остановлен на длительное время
- Если включена настройка `BATCH_PROCESSING_ENABLED`

**Процесс:**
1. Агент проверяет все активные правила
2. Для каждого правила проверяет последнее обработанное сообщение
3. Агент обрабатывает все новые сообщения с момента последней обработки
4. Сообщения отправляются в целевые каналы

**Ограничения:**
- Максимальное количество сообщений в пакете: **100** (настраивается через `MAX_BATCH_SIZE`)
- Интервал между пакетными обработками: **60 секунд** (настраивается через `BATCH_PROCESSING_INTERVAL`)
- Задержка между правилами: **2 секунды** (настраивается через `RULE_SWITCH_DELAY`)

#### Обработка в реальном времени

**Когда происходит:**
- После завершения пакетной обработки
- При обычной работе агента

**Процесс:**
1. Агент подписывается на новые сообщения в каналах-источниках
2. При получении нового сообщения агент обрабатывает его
3. Обработанное сообщение отправляется в целевой канал

**Ограничения:**
- Обрабатываются только новые сообщения (после запуска агента)
- Медиа-группы обрабатываются как единое целое
- Ограничение на скорость обработки (flood wait)

#### Flood Wait

Telegram API имеет ограничения на скорость отправки сообщений. При превышении лимита возникает **flood wait** — задержка перед следующей отправкой.

**Как система обрабатывает flood wait:**
1. Агент получает уведомление о flood wait
2. Агент ждет указанное время (умноженное на `FLOOD_WAIT_MULTIPLIER`, по умолчанию 1.0)
3. После ожидания агент продолжает работу

**Ограничения:**
- Максимальное время ожидания: **60 минут**
- Если flood wait превышает 60 минут, агент переходит в состояние `error`

### Запланированные посты

#### Что такое запланированные посты?

Запланированные посты — это сообщения, которые были отложены из-за ограничений Telegram или настроек агента.

**Причины планирования:**
- Flood wait (ограничение скорости Telegram)
- Ошибка отправки (временная)
- Настройка задержки между сообщениями

#### Просмотр запланированных постов

**Как просмотреть:**
1. Через веб: Вкладка "Активность" → "Запланированные посты"
2. Через API: `GET /api/workers/logs/scheduled_posts`

**Информация о посте:**
- ID правила
- ID исходного сообщения
- Время планирования
- Статус (pending, sent, failed)
- Ошибка (если есть)

#### Ограничения

- Максимальное время хранения запланированного поста: **24 часа**
- После 24 часов пост удаляется из очереди
- Максимальное количество запланированных постов: **1000**

## Интерфейс веб-приложения

### Доступ к веб-приложению

Веб-приложение доступно по адресу: `https://your-domain.com`

Также доступно как **Telegram Mini App** через бота.

### Авторизация

#### Способы авторизации

1. **Через Telegram Mini App**:
   - Откройте бота
   - Нажмите на кнопку веб-приложения
   - Автоматическая авторизация через Telegram

2. **Через веб-форму**:
   - Откройте веб-приложение
   - Введите номер телефона
   - Получите код через Telegram
   - Введите код (и 2FA пароль, если включен)

3. **Backdoor autologin** (только для разработки):
   - Автоматическая авторизация для тестового пользователя
   - Включается через переменную окружения

#### Требования к сессии

Для работы агента требуется **файл сессии Telegram**:
- Файл сессии создается при первой авторизации через телефон
- Файл хранится в S3
- Без файла сессии агент не может работать

**Если файл сессии отсутствует:**
- Система покажет форму входа по телефону
- Вам нужно авторизоваться заново

### Вкладки интерфейса

#### Главная (Home)

Показывает:
- Информацию о пользователе (имя, баланс, VIP-уровень)
- Статус агента
- Кнопки управления агентом (Запустить/Остановить)
- Статистику (количество правил, сообщений)

**Действия:**
- Запустить/остановить агента
- Перейти к активности
- Перейти к каналам

#### Активность (Activity)

Показывает:
- **Логи в реальном времени**: Журнал работы агента через WebSocket
- **Запланированные посты**: Список отложенных сообщений
- **Ошибки агента**: Журнал ошибок

**Логи в реальном времени:**
- Обновляются автоматически через WebSocket
- Показывают последние 50 записей
- Поддерживают переводы на русский язык

**Ограничения:**
- Логи хранятся только в течение сессии
- При перезагрузке страницы логи очищаются

#### Каналы (Channels)

Показывает:
- **Список правил**: Все созданные правила каналов
- **Кнопка создания**: Создать новое правило
- **Управление правилами**: Редактировать, удалить, активировать/деактивировать

**Создание правила:**
- Открывает мастер создания правил (RuleWizard)
- Пошаговое заполнение формы
- Предпросмотр перед сохранением

**Ограничения:**
- Для создания правила нужны права админа в целевом канале
- Источник должен быть в списке подписанных каналов

#### Настройки (Settings)

Показывает:
- **Информация о пользователе**: Имя, ID, язык
- **Смена языка**: Русский/English
- **Выход**: Выйти из аккаунта
- **Переключение дизайна**: Оригинальный/Переработанный UI
- **Обновление аккаунта**: Обновить данные аккаунта (для TMA)

### WebSocket соединение

Веб-приложение использует WebSocket для получения логов в реальном времени.

**URL WebSocket:**
```
ws://your-domain.com/api/ws/{user_id}
```

**Типы сообщений:**
- `log`: Новая запись в логе

**Переподключение:**

- Интервал переподключения: **3 секунды**
- Fallback на HTTP-опросы каждые **5 секунд** (если WebSocket недоступен)

## Система приоритетов и VIP

### VIP-уровни

Система имеет 4 VIP-уровня:

| Уровень | Приоритет | Преимущества |
|--------|-----------|--------------|
| **VIP 3** | 300 | Мгновенный запуск, максимальная очередь, отчеты по расписанию |
| **VIP 2** | 200 | Приоритет в очереди, расширенные функции |
| **VIP 1** | 100 | Повышенный приоритет |
| **Обычный** | 0 | Базовый приоритет |

### Система новичков (Newcomer)

**Новичок** — это пользователь, зарегистрировавшийся менее 24 часов назад.

**Преимущества новичка:**
- Приоритет: **1000** (выше VIP3)
- Быстрый запуск агента
- Приоритет в очереди

**Ограничения:**
- Статус новичка автоматически снимается через 24 часа
- После 24 часов приоритет снижается до базового

### Очередь агентов

Агенты запускаются по очереди на основе приоритета.

**Алгоритм очереди:**
1. Сортировка по приоритету (по убыванию)
2. При равном приоритете — FIFO (первым пришел, первым ушел)
3. VIP3 могут автоматически добавляться в очередь (периодическая инъекция)

**Максимальное количество одновременно работающих агентов:**
- Настраивается через переменную окружения `MAX_CONCURRENT_WORKERS`
- По умолчанию: **10**

**Проверка неактивных агентов:**
- Агент считается неактивным, если нет heartbeat более 30 секунд
- Неактивные агенты автоматически останавливаются
- Проверка происходит каждые **10 секунд**

## Ограничения и нюансы

### Ограничения Telegram API

1. **Flood Wait**:
   - Ограничение на скорость отправки сообщений
   - Время ожидания зависит от объема отправки
   - Может достигать нескольких минут

2. **Медиа-группы**:
   - Максимум 10 элементов в группе
   - Группа обрабатывается как единое целое
   - Подпись к группе — одна для всех элементов

3. **Размер файлов**:
   - Максимальный размер фото: **10 MB**
   - Максимальный размер видео: **2 GB**
   - Ограничения Telegram API

### Ограничения OpenRouter API

1. **Rate Limiting**:
   - Минимальный интервал между запросами: **5 секунд**
   - Применяется для бота и агента
   - При превышении запрос отклоняется

2. **Стоимость**:
   - Зависит от выбранной модели
   - Списывается в батареях
   - Разные модели имеют разную стоимость

3. **Доступность**:
   - Требуется работающий интернет
   - API может быть временно недоступен
   - При ошибке запрос повторяется

### Ограничения баланса

1. **Минимальный баланс**:
   - Баланс не может быть отрицательным
   - При отрицательном балансе агент не запустится
   - Бот не будет обрабатывать сообщения

2. **Списание**:
   - Списание происходит при успешной обработке
   - При ошибке баланс не списывается
   - Списывается за каждое сообщение

3. **Бесплатные батареи**:
   - Можно получить каждые 8 часов
   - Количество: 10 батарей
   - Таймер сбрасывается после получения

### Ограничения агента

1. **Количество правил**:
   - Минимум: 1 правило для запуска
   - Максимум: 50 правил на пользователя

2. **Количество агентов**:
   - Максимум: 1 агент на пользователя
   - Нельзя запустить несколько агентов одновременно

3. **Время работы**:
   - Агент работает неограниченно
   - Автоматическая остановка при неактивности (настраивается)
   - VIP-уровни имеют разное время неактивности

### Ограничения веб-интерфейса

1. **Логи**:
   - Хранятся только в течение сессии
   - Максимум 50 записей
   - Очищаются при перезагрузке страницы

2. **WebSocket**:
   - Требуется поддержка WebSocket в браузере
   - Fallback на HTTP-опросы при недоступности
   - Интервал опроса: 5 секунд

3. **TMA (Telegram Mini App)**:
   - Работает только внутри Telegram
   - Автоматическая авторизация
   - Мониторинг смены аккаунта

### Нюансы работы

1. **Первая авторизация**:
   - Требуется ввод номера телефона
   - Требуется ввод кода из Telegram
   - Опционально: 2FA пароль
   - Создается файл сессии в S3

2. **Смена аккаунта в TMA**:
   - Приложение автоматически обнаруживает смену
   - Требуется обновление данных
   - Агент останавливается при смене

3. **Язык интерфейса**:
   - Язык сохраняется в профиле пользователя
   - Применяется ко всем сообщениям бота и веб-интерфейса
   - Можно сменить в любой момент

4. **Подписи к сообщениям**:
   - Добавляются в конце пересылаемого сообщения
   - Формат: `Текст сообщения\n\nПодпись`
   - Можно включить/отключить для каждого правила

5. **Медиа без подписи**:
   - Медиа без подписи пересылаются без изменений
   - ИИ-обработка не применяется
   - Баланс не списывается

6. **Длинные сообщения**:
   - Сообщения длиннее 4096 символов разбиваются
   - Разбиение сохраняет целостность предложений
   - Каждая часть отправляется отдельно

## Устранение неполадок

### Агент не запускается

**Возможные причины:**

1. **Нет правил каналов**
   - Решение: Создайте хотя бы одно правило

2. **Отрицательный баланс**
   - Решение: Пополните баланс через Telegram Stars

3. **Отсутствует файл сессии**
   - Решение: Авторизуйтесь заново через телефон

4. **Агент уже запущен**
   - Решение: Остановите текущий агент перед запуском нового

5. **Ошибка авторизации**
   - Решение: Проверьте правильность ввода кода и 2FA пароля

### Агент остановился с ошибкой

**Возможные причины:**

1. **Flood wait слишком долгий**
   - Решение: Подождите или перезапустите агента позже

2. **Ошибка Telegram API**
   - Решение: Проверьте подключение к интернету

3. **Ошибка OpenRouter API**
   - Решение: Проверьте баланс и доступность API

4. **Ошибка сессии**
   - Решение: Авторизуйтесь заново

### Бот не отвечает

**Возможные причины:**

1. **Сервер недоступен**
   - Решение: Проверьте статус сервера

2. **Ошибка конфигурации**
   - Решение: Свяжитесь с администратором

3. **Rate limiting**
   - Решение: Подождите 5 секунд перед следующим запросом

### Веб-интерфейс не работает

**Возможные причины:**

1. **Ошибка конфигурации окружения**
   - Решение: Проверьте переменные окружения
   - Решение: Перезапустите приложение

2. **Ошибка S3**
   - Решение: Проверьте credentials S3
   - Решение: Проверьте подключение к S3

3. **WebSocket не подключается**
   - Решение: Проверьте поддержку WebSocket в браузере
   - Решение: Используйте fallback на HTTP-опросы

### Логи не обновляются

**Возможные причины:**

1. **WebSocket отключен**
   - Решение: Проверьте подключение к интернету
   - Решение: Перегрузите страницу

2. **Агент не работает**
   - Решение: Запустите агента

3. **Ошибки в логах**
   - Решение: Проверьте вкладку "Ошибки агента"

### Баланс не пополнился

**Возможные причины:**

1. **Ошибка платежа**
   - Решение: Проверьте статус платежа в Telegram
   - Решение: Свяжитесь с поддержкой Telegram

2. **Ошибка сервера**
   - Решение: Попробуйте повторить оплату позже

3. **Задержка обработки**
   - Решение: Подождите несколько минут

### Сообщения не пересылаются

**Возможные причины:**

1. **Правило неактивно**
   - Решение: Активируйте правило

2. **Нет прав в целевом канале**
   - Решение: Получите права админа

3. **Канал-источник недоступен**
   - Решение: Проверьте подписку на канал

4. **Агент не запущен**
   - Решение: Запустите агента
