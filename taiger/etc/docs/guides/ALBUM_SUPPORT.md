# Руководство по работе с альбомами фотографий

## Что изменилось?

Теперь система полностью поддерживает обработку альбомов фотографий! 📸

## Как это работает?

### Раньше:
- При пересылке альбома фотографий в черновик
- Система отправляла сообщение: "Sorry, this post format is not supported"
- Альбом не обрабатывался

### Теперь:
- При пересылке альбома фотографий в черновик
- Система автоматически собирает все фотографии альбома
- Обрабатывает текст подписи через ИИ (если настроено)
- Отправляет весь альбом в чистовик как единое целое

## Особенности работы с альбомами

### 📝 Обработка текста
- **С подписью**: Если у альбома есть подпись, она обрабатывается ИИ как обычно
- **Без подписи**: Если подписи нет, используется стандартный текст "📸 Альбом фотографий"
- **Удаление текста**: Работают все настроенные правила удаления текста
- **ИИ обработка**: Применяются все настроенные модели и параметры ИИ

### 🖼️ Обработка фотографий
- **Порядок**: Сохраняется исходный порядок фотографий в альбоме
- **Качество**: Фотографии отправляются в исходном качестве
- **Количество**: Поддерживается любое количество фотографий в альбоме
- **Смешанный контент**: Поддерживаются альбомы с фотографиями и видео

### ⏰ Планирование
- **Единое время**: Весь альбом планируется на одно время
- **Задержка**: Применяются обычные правила задержки публикации
- **Очередь**: Альбом занимает одно место в очереди публикаций

### 💰 Списание баланса
- **Один раз**: Баланс списывается один раз за весь альбом
- **Как обычно**: Применяются стандартные тарифы за обработку поста
- **ИИ обработка**: Если используется ИИ, списывается соответствующая сумма

## Примеры использования

### Пример 1: Альбом с подписью
```
Исходный альбом:
📸 Фото 1
📸 Фото 2  
📸 Фото 3
Подпись: "Красивые фотографии природы"

Результат в чистовике:
📸 Фото 1 (с обработанной подписью)
📸 Фото 2
📸 Фото 3
```

### Пример 2: Альбом без подписи
```
Исходный альбом:
📸 Фото 1
📸 Фото 2

Результат в чистовике:
📸 Фото 1 (с подписью "📸 Альбом фотографий")
📸 Фото 2
```

### Пример 3: Альбом с удалением текста
```
Настройка: удалить "РЕКЛАМА:"
Исходная подпись: "РЕКЛАМА: Красивые фотографии"

Результат: "Красивые фотографии" (обработано ИИ)
```

## Технические детали

### Как система определяет альбом?
- Telegram отправляет сообщения альбома с одинаковым `media_group_id`
- Система собирает все сообщения с одним `media_group_id` в течение 2 секунд
- После сбора обрабатывает альбом как единое целое

### Что происходит при обработке?
1. **Сбор**: Система ждет все сообщения альбома
2. **Сортировка**: Сообщения сортируются по ID для сохранения порядка
3. **Извлечение текста**: Берется подпись из первого сообщения с текстом
4. **Обработка**: Применяются правила удаления и ИИ обработка
5. **Отправка**: Весь альбом отправляется в целевой канал

### Логирование
- Все операции с альбомами подробно логируются
- В панели управления отображается статус обработки альбомов
- Ошибки обработки альбомов отслеживаются отдельно

## Совместимость

- ✅ Полностью совместимо с существующими правилами
- ✅ Работает со всеми настроенными моделями ИИ
- ✅ Поддерживает все параметры обработки (температура, токены и т.д.)
- ✅ Совместимо с системой планирования публикаций
- ✅ Работает с системой приоритетов пользователей

## Устранение неполадок

### Альбом не обрабатывается
- Проверьте, что правило настроено для канала-черновика
- Убедитесь, что баланс положительный
- Проверьте логи агента в панели управления

### Неправильный порядок фотографий
- Это может происходить при медленном интернете
- Система автоматически сортирует фотографии по ID сообщений
- Обычно порядок сохраняется корректно

### Проблемы с подписью
- Если подпись не обрабатывается, проверьте настройки ИИ модели
- При ошибках ИИ используется исходная подпись
- Если подписи нет, используется стандартный текст

## Поддержка

Если у вас возникли проблемы с обработкой альбомов:
1. Проверьте логи агента в панели управления
2. Убедитесь, что используется последняя версия системы
3. Обратитесь в поддержку с описанием проблемы и скриншотами
