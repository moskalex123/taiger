# 🌟 Система "Новичок" - Руководство

## Обзор

Система "Новичок" предоставляет новым пользователям максимальный приоритет в очереди запуска воркеров в течение первых 24 часов после регистрации. Это помогает новым пользователям быстро оценить сервис и снижает вероятность их ухода из-за долгого ожидания.

## Ключевые особенности

### 🎯 Приоритеты в очереди

1. **Новичок** (приоритет 1000) - первые 24 часа после регистрации
2. **VIP 3** (приоритет 300) - пользователи с VIP уровнем 3+
3. **VIP 2** (приоритет 200) - пользователи с VIP уровнем 2
4. **VIP 1** (приоритет 100) - пользователи с VIP уровнем 1
5. **Обычный** (приоритет 0) - все остальные пользователи

### 🎨 Визуальное отображение

- **Новички** отображаются с ярко-желтым фоном (#FFD700) и звездочкой 🌟
- Анимация мерцания для привлечения внимания
- Специальная подсказка при наведении

## Логика работы

### Определение статуса новичка

```python
async def is_user_newcomer(user: User) -> bool:
    if not user.is_newcomer:
        return False
    
    if user.created_at:
        time_since_creation = datetime.utcnow() - user.created_at
        if time_since_creation > timedelta(hours=24):
            user.is_newcomer = False
            return False
    
    return True
```

### Расчет приоритета

```python
async def get_user_priority(db_session: AsyncSession, user_id: int) -> tuple[int, str, bool]:
    user = await db_session.get(User, user_id)
    
    is_newcomer = await is_user_newcomer(user)
    if is_newcomer:
        return NEWCOMER_PRIORITY, "newcomer", True
```

## Мониторинг и статистика

### Фоновая задача очистки

- Запускается каждый час
- Автоматически обновляет статус пользователей старше 24 часов
- Логирует все изменения

### Статистика новичков

```python
from newcomer_cleanup_task import get_newcomer_cleanup_task

task = get_newcomer_cleanup_task()
stats = await task.get_newcomer_stats()
```

Возвращает:
- `active_newcomers` - активные новички
- `new_in_hour` - новые за последний час
- `new_in_6_hours` - новые за последние 6 часов
- `graduated_today` - "выпустившиеся" сегодня

## Устранение неполадок

### Проблема: Новички не получают приоритет

1. Проверьте, что поле `is_newcomer` добавлено в БД:
   ```sql
   SELECT column_name FROM information_schema.columns 
   WHERE table_name = 'users' AND column_name = 'is_newcomer';
   ```

2. Проверьте, что фоновая задача запущена:
   ```bash
   grep "Фоновая задача очистки статусов новичков запущена" logs/app.log
   ```

### Проблема: Статус новичка не сбрасывается

1. Проверьте работу фоновой задачи:
   ```python
   python newcomer_cleanup_task.py
   ```

2. Ручной сброс статуса:
   ```sql
   UPDATE users SET is_newcomer = FALSE 
   WHERE created_at < NOW() - INTERVAL '24 hours';
   ```

### Проблема: Новички не отображаются на фронтенде

### Мониторинг производительности

```sql
-- Количество новичков
SELECT COUNT(*) FROM users WHERE is_newcomer = TRUE;

-- Статистика по времени создания
SELECT 
  DATE_TRUNC('hour', created_at) as hour,
  COUNT(*) as new_users,
  COUNT(*) FILTER (WHERE is_newcomer = TRUE) as newcomers
FROM users 
WHERE created_at > NOW() - INTERVAL '24 hours'
GROUP BY hour
ORDER BY hour;
```
