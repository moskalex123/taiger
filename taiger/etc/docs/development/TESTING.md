# Инструкция по тестированию автоматического переключения аккаунтов TMA

## 🧪 Как протестировать улучшения

### Метод 1: Реальное тестирование в Telegram

1. **Откройте приложение в мобильном Telegram**
2. **Войдите под первым аккаунтом** и убедитесь, что приложение работает
3. **Переключитесь на другой аккаунт Telegram** (Настройки → Аккаунты → Переключить)
4. **Вернитесь в Mini App** и проверьте:
   - Автоматически ли обновились данные пользователя (должно произойти в течение 2-4 секунд)
   - Если автоматически не сработало, используйте кнопку "Обновить аккаунт" в настройках

### Метод 2: Интерактивное тестирование

1. **Откройте файл `test_tma_auto_detection.html`** в браузере
2. **Следуйте инструкциям на странице:**
   - Настройте Mock TMA
   - Выберите первого пользователя
   - Запустите тест автообнаружения
   - Переключитесь на другого пользователя
   - Наблюдайте за автоматическим обнаружением в логе

### Метод 3: Backend тестирование

```bash
python test_tma_account_switch.py
```

## 🔍 Что проверять

### Автоматическое обнаружение должно сработать при:
- ✅ Переключении аккаунта в Telegram
- ✅ Возврате в приложение после переключения
- ✅ Фокусе на окне браузера после смены аккаунта
- ✅ Изменении initData в TMA

### Ручное обновление должно работать:
- ✅ Кнопка "Обновить аккаунт" в настройках
- ✅ Показ спиннера во время обновления
- ✅ Корректное переключение данных пользователя

## 📊 Ожидаемые результаты

### В консоли браузера должны появиться логи:
```
🔍 Starting enhanced account monitoring for TMA...
🔄 TMA initData change detected
🚨 Account switch detected, triggering refresh...
✅ Account switch completed successfully
🆔 New user ID: [новый ID]
```

### В интерфейсе должно произойти:
1. Обновление данных пользователя (имя, баланс, ID)
2. Перезагрузка данных воркера
3. Обновление логов и активности

## 🐛 Возможные проблемы

### Если автоматическое обнаружение не работает:
1. Проверьте консоль на ошибки
2. Убедитесь, что TMA правильно инициализирован
3. Попробуйте ручное обновление через кнопку
4. Проверьте, что мониторинг запущен

### Если ручное обновление не работает:
1. Проверьте сетевое соединение
2. Убедитесь, что backend доступен
3. Проверьте токены в localStorage
