# Архитектура проекта

## Обзор

Taiger - это система автоматической обработки постов из Telegram-каналов с помощью ИИ. Проект построен на микросервисной архитектуре с разделением на backend (FastAPI) и frontend (Vue 3).

## Основные компоненты

### Backend (FastAPI)

- **main.py** - Точка входа, настройка FastAPI приложения
- **api/** - API endpoints для различных функций
- **telegram_worker/** - Обработка Telegram сообщений
- **telegram_bot/** - Telegram бот для промо-режима
- **models.py** - SQLAlchemy модели базы данных
- **db.py** - Настройка подключения к базе данных

### Frontend (Vue 3)

- **src/components/** - Vue компоненты
- **src/services/** - API сервисы
- **src/composables/** - Vue composables
- **src/locales/** - Локализация (ru/en)

### База данных (PostgreSQL)

Основные таблицы:
- `users` - Пользователи
- `telegram_sessions` - Сессии Telegram
- `workers` - Статусы воркеров
- `channel_pairs` - Правила обработки
- `models` - ИИ модели
- `scheduled_posts` - Запланированные публикации

### Кэш (Redis)

- Очереди воркеров
- Временные данные
- Сессии

## Поток данных

```
Пользователь → TMA/Bot → API → Worker → Telegram API → ИИ обработка → Публикация
```

## Система воркеров

Каждый пользователь имеет свой изолированный процесс воркера:
- Управление через `worker_manager.py`
- Регистрация в `worker_registry.py`
- Очередь через `queue_manager.py`

## Обработка сообщений

1. Воркер получает сообщение из канала-источника
2. Применяет правила обработки (удаление текста, ИИ обработка)
3. Планирует публикацию в канал-приёмник
4. Отправляет в запланированное время

## ИИ обработка

- Универсальный процессор (`uni_text_processor/`)
- Поддержка нескольких провайдеров (OpenRouter, Hyperbolic)
- Настраиваемые параметры моделей

## Безопасность

- JWT токены для авторизации
- Валидация Telegram данных через HMAC
- Хранение сессий в Yandex Object Storage
- Изоляция процессов воркеров
